# Анализ продаж и прибыльности Superstore

## О проекте

Проект посвящён анализу продаж и прибыльности розничного магазина на основе набора данных Superstore за 2014–2017 годы.

Цель — изучить динамику продаж и прибыли, сравнить результаты категорий товаров, регионов и клиентских сегментов, а также выявить товары с отрицательной рентабельностью.

В проекте используются SQL для анализа данных и Power BI для визуализации результатов.

## Инструменты

- **SQL (SQLite)** — проверка качества данных, агрегирование показателей и анализ прибыльности.
- **Power BI** — интерактивный дашборд, KPI-показатели, фильтры и графики динамики.
- **DAX** — расчёт рентабельности и показателей убыточности товаров.

## Основные бизнес-вопросы

- Как менялись продажи и прибыль с течением времени?
- Какие категории и подкатегории товаров приносили наибольшую прибыль?
- Чем различались результаты регионов и клиентских сегментов?
- Как уровень скидки связан с показателями прибыльности?
- Какие товары из категории «Furniture → Tables» имели рентабельность ниже −10%?

## Основные результаты

- Набор данных содержит **9 994 строки заказов** и **5 009 уникальных заказов**.
- Период данных — с января 2014 года по декабрь 2017 года.
- Выявлено **24 товара** из категории Furniture → Tables с рентабельностью ниже −10%.
- Сопоставление выручки, прибыли и рентабельности помогает отличать высокий объём продаж от высокой прибыльности.

## Как запустить проект

### Power BI

1. Откройте `successful_project.pbix` в Power BI Desktop.
2. Если программа запросит путь к источнику данных, укажите `data/Sample - Superstore.csv`.
3. При необходимости обновите данные.

### SQL

1. Откройте `data/superstore.db` в DBeaver или другом клиенте SQLite.
2. Убедитесь, что в базе есть таблица `orders` с ожидаемыми названиями столбцов.
3. Откройте `sql/superstore_analysis.sql`.
4. Выполните весь скрипт, чтобы просмотреть результаты проверок и анализа.

## Методика расчёта

Рентабельность рассчитывается по формуле:

`Рентабельность = Общая прибыль / Общая выручка`

В анализе категории Furniture → Tables товар считается низкорентабельным, если его рентабельность ниже −10%.

Результаты описывают закономерности в наборе данных, но сами по себе не доказывают причины возникновения убытков.
